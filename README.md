# Precision Forge

MASTER WEBSITE DEVELOPMENT PROMPT

PROJECT

Build a premium, modern, high-performance, multi-page website for a professional metal manufacturing / sheet metal production company.

The website must feel like a real established industrial manufacturing company — not an AI-generated website, not a generic Bootstrap template, and not a startup landing page.

Use these websites ONLY as visual and structural references:

https://www.shdmold.com/

https://www.grenterprisesindia.com/

Do NOT copy their branding, text, layouts, images, logos, colors, or exact UI.

Study the references for:

visual hierarchy

hero composition

image treatment

product presentation

product galleries

industrial storytelling

card layouts

hover interactions

section spacing

typography

animations

scroll behavior

manufacturing credibility

industry/category presentation

Create a completely original website inspired by the quality level and interaction patterns of these references.
